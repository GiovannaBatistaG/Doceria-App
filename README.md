# Doceria App

Aplicativo desenvolvido em Flutter para gerenciamento e visualização de receitas de doces.

## Funcionalidades

* Listagem de doces
* Visualização de detalhes
* Favoritar receitas
* Tela de favoritos
* Navegação com BottomNavigationBar
* Menu lateral (Drawer)
* Interface desenvolvida com Flutter

## Tecnologias Utilizadas

* Flutter
* Dart
* Material Design
* flutter_animate

## Como Executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta:

```bash
cd book_receitas
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute o projeto:

```bash
flutter run
```
